Leçon 3 : le passé simple

Le passé simple exprime une action achevée dans le passé, souvent dans un récit. On l'emploie surtout à l'écrit.

1er groupe : chanter

  • je chantai
  • tu chantas
  • il / elle chanta
  • nous chantâmes
  • vous chantâtes
  • ils / elles chantèrent

2e groupe : finir

  • je finis
  • tu finis
  • il / elle finit
  • nous finîmes
  • vous finîtes
  • ils / elles finirent
